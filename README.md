# Anne Pilates — Studio de Pilates & Méthode de Gasquet à Versailles

Site vitrine pour le studio **Anne Pilates** à Versailles, animé par Anne Burger (certifiée Polestar Studio, Body Control Pilates Londres & Institut de Gasquet).

## 🚀 Liens

- **Production Vercel :** [https://anne-pilates.vercel.app](https://anne-pilates.vercel.app)
- **Dépôt GitHub :** [https://github.com/Kitemi-Studio/anne-pilates](https://github.com/Kitemi-Studio/anne-pilates)

## 🛠️ Stack Technique

- **Framework :** Next.js 16 (App Router, Turbopack, React 19)
- **Styles :** Tailwind CSS v4
- **Animations :** Framer Motion
- **SEO & AIO :** Données structurées Schema.org (`SportsActivityLocation`), robots.txt optimisé GEO/AIO, sitemap XML
